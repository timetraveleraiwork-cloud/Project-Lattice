# Week 2 Day 2 - Graph Schema Design

## Objective

The objective of this exercise is to design a property graph schema before implementing it in Neo4j.

Instead of immediately creating nodes and relationships, the schema models the real-world business domain and documents:

- Node types
- Properties
- Relationships
- Design decisions
- Example Cypher queries

This follows the graph-first design methodology used in production systems.

- sample_data.cypher — Example dataset
